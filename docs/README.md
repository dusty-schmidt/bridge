# Docs index

- `README.md` (root) — install, usage, commands.
- `CHANGELOG.md` (root) — what changed, by date.
- `ARCHITECTURE.md` — components and flow.
- `decisions/` — one file per decision that changed or fixed behavior (ADR format: Context / Decision / Consequences).
- `handoffs/` — one file per work session, dated, for the next person (or agent) to read cold.

Rule: a change that alters behavior updates the relevant doc in the same change. No separate doc-catch-up pass.
